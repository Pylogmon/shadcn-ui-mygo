# Create fonts

The fixed shadcn Create picker offers 26 named families. This package supplies
their original Google Fonts TrueType files, including original italic faces
where provided. Fonts are embedded, work offline and use MyGo's public
`ui.RegisterFont`; they require no operating-system installation.

For selected families, use the individual functions. Other families' assets
can be removed by the Go linker:

```go
body := fonts.Inter()
heading := fonts.PlayfairDisplay()
if err := body.Register(); err != nil { return err }
if err := heading.Register(); err != nil { return err }
roles := theme.FontRoles{Body: body.Family(), Heading: heading.Family()}
// In the current view:
theme.FontScope(c, roles).Children(func() { /* native components */ })
```

`fonts.Catalog()` returns metadata only and does not reference font assets.
`Font.Info()` returns the source ID, display name, native family, kind,
source-supported 100-step weights and original italic availability. The
metadata is copied; changing it cannot modify a registered descriptor.

For a complete picker, explicitly import `pkg/fonts/all`:

```go
if err := fontall.Register(); err != nil { return err }
font, ok := fontall.Lookup("noto-sans")
if ok { nativeFamily = font.Family() }
```

`all.Families()` keeps the fixed source picker order. Importing either package
does not register a font automatically. `Font.Register` is safe to repeat and
retains its first result. The full catalogue links all assets; the individual
functions are the on-demand path.

The 47 original Google Fonts files remain unchanged. Native font matching
selects their weight/style faces; the concentrated macOS native test checks
actual 400/500/600/700/800 glyph differences where those weights exist. These
are the weights used by the kit, including the 800 H1. Instrument Serif
is the original regular 400 family, not a fabricated set of bold weights.
Two source variables omit a 600 named face, causing the native matcher to
select the same glyphs for 500 and 600. JetBrains Mono includes its author's
unchanged SemiBold/SemiBoldItalic files and notice from official `v2.304`
(`cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`). Space Grotesk's fixed author's
static release contains only 300/400/500/700, so the package adds one 600
instance of the pinned variable file. Its distinct internal family is
`Native Go Font 13`; public registration joins it to Space Grotesk. The
original copyright and OFL records remain, and source/derived bytes and
generation steps are recorded separately in the manifest.

No arbitrary variation-axis control is added. Unprovided italic faces and
intermediate weights follow the native backend's matching behavior. Metadata
describes the source-supported range, not a promise that every weight has
been exercised on every platform. The test
does not establish Windows/Linux runtime, IME or assistive-technology acceptance.

`manifest.json` pins Google Fonts commit
`5bb28733cec313b63fbd415b574b5ae35c8aa8b8`, each original Git blob, SHA-256,
byte count and package path. The fixed source font definitions and picker are
in `testdata/shadcn`; the existing source font-role implementation remains in
`pkg/theme`. Vega uses Inter with inherited headings; Sera uses Noto Sans with
Playfair Display headings.

Each family retains its original license and copyright files under `assets`.
Roboto Slab uses its original Apache license; the other families supply their
original OFL notices. Include the notices with distributed applications;
`Font.Licenses()` returns their unchanged text for this purpose.

`go generate ./pkg/fonts` verifies existing original assets and regenerates
the small Go entry points, entirely offline and without extra tools. From
`pkg/fonts`, `go run ./internal/generate -source-dir /path/to/google-fonts`
can restore missing files from a checkout; `-download` explicitly fetches
missing files from the pinned official commit. All three paths verify the
original bytes before writing output. The committed Space Grotesk instance
is verified rather than regenerated by this command. Restoring that single
file uses `python3 internal/generate/static-instance.py` with the fixed
`fonttools==4.60.1`; all axes are pinned, source timestamps are retained, and
repeated generation produces identical bytes. No other font is transformed,
and no font is subsetted.
