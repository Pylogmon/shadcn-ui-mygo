# Dropdown Menu source compositions

Gallery's Dropdown Menu card exposes 27 source configurations: all 13 docs examples and all 14 sections of the Create collection at shadcn/ui commit `8ab27715521cbd4f87ae6886cd989cbb678f6de7`. The default is the docs Demo. `source-map.json` records each recipe, original blob/SHA-256/URL, and adaptations.

The docs recipes cover Demo, Basic, Icons, Shortcuts, Submenu, Checkboxes, Checkboxes with Icons, Radio Group, Radio with Icons, Destructive, Avatar, Complex and RTL. Create exposes Basic, Sides, With Icons, With Shortcuts, With Submenu, With Checkboxes, With Radio, Checkboxes with Icons, Radio with Icons, With Destructive Items, With Avatar, In Dialog, With Inset and Complex. Each recipe owns its source checkbox/radio defaults; aliases within a complex source share the same state. Arabic, Hebrew and English source translations are selectable for RTL.

Create Sides has six real triggers. Create Avatar has the original account trigger plus top/end avatar trigger and reuses the existing original shadcn bitmap. In Dialog uses a real modal around the independent dropdown. Source app actions update a local status; these examples do not claim network, filesystem, account or clipboard effects. Business icons use semantic Material Symbols SVG equivalents. Submenu arrows reuse the fixed 16-pixel decorative Chevron SVG, rotated for LTR/RTL, so bidi text mirroring cannot reverse their direction. No icon font or new font is introduced.

Styled menus use `desktop.DropdownMenu` and a parent-bound Host. Their content is built with the current child Context. Native menus use `desktop.NativeDropdownMenu` and MyGo's SystemMenus adapter; the operating system owns appearance, placement and menu tracking. Source business icons are recursively converted with `mygo.NewMenuIconSVG` into cached template `ui.MenuIcon` handles; the OS may render, size or suppress them according to its native menu conventions. Source rich styling and Inset are visual options on the styled route.

`MenuItem.Inset` changes logical start padding from 8 to 32 pixels. `GroupInset` independently indents its group caption. Checked/radio rows reserve 32 pixels at logical end and render the shared 16-pixel Check SVG at end 8; their independent leading business icon remains visible. Ordinary actions close by default while checkbox/radio selections remain open. `CloseOnSelect` overrides a row and global `KeepOpenOnSelect` takes priority. The fixed Base UI 1.6.0 originals are archived under `pkg/desktop/testdata/shadcn-menu/close-on-click`.

The concentrated public Tester workflow verifies source configuration selection, native menu tracking and nested state, independent styled menu content, source Inset, RTL keyboard submenus, six sides, avatar placement and dialog actions. The SDK workflow verifies actual 24-pixel geometry, caption ink positions, both business icons and ending indicators, semantic state and selection closing. Optional software-rendered PNGs use `GALLERY_DROPDOWN_COMPOSITION_SNAPSHOT_DIR`; they are MyGo Tester evidence, not screenshots of a real OS menu. The injected test backend does not implement the native fitter: submenu software viewports are explicitly expanded to the summed measured panel widths before capture. This is content/geometry evidence and does not certify the real native fitter.
